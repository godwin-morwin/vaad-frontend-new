# VAAD User App

The customer-facing VAAD web application, built with Next.js and React.

## Development

Install dependencies from this directory with pnpm, then start the app:

```sh
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000). Configure `NEXT_PUBLIC_API_URL` and `NEXT_PUBLIC_APP_URL` in `.env.local` before using API-backed features.

## Available commands

- `pnpm dev` starts the local development server.
- `pnpm build` creates a production build.
- `pnpm start` serves the production build.
- `pnpm lint` runs ESLint.

## Stack

Next.js App Router, React, TypeScript, Tailwind CSS, and the VAAD shared UI packages.
